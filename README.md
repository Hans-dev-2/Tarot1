# Tarot1
supports tarot1.neocities.org

We are building a web-based Tarot Card Generator using plain HTML, CSS, and vanilla JavaScript. 

/project-root
├── index.html
├── style.css
├── meanings.js     // Core dictionary (0-155 lookup, base meanings)
├──  3cards.js       // 3-Card specific narrative synthesis engine
├── tarot.js        // App controller: Deck shuffling, click handler, flip states
